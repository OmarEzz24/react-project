
# React Project Setup

A React project initialized with Vite and configured with Tailwind CSS.

## Tech Stack

- React
- Vite
- Tailwind CSS v4
- Zustand
- Yup
- ESLint

## Project Structure

```text
src/
├── assets/
├── components/
│   ├── common/
│   └── layout/
├── features/
├── hooks/
├── layouts/
├── pages/
├── services/
├── stores/
├── utils/
├── App.jsx
├── main.jsx
├── index.css
└── theme.css
```

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```

### 4. Run ESLint

```bash
npm run lint
```

## Design Tokens

Custom design tokens are defined in `src/theme.css`.
